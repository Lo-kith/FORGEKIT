# __PROJECT_NAME__

A full-stack starter generated by create-forgekit.

## Stack

- **Web:** React, Vite, and TypeScript (`web/`)
- **API:** Express and TypeScript (`api/`)
- **Database:** MongoDB via Mongoose (optional at startup)

## Getting started

1. Install dependencies from the project root:

   ```sh
   npm install
   ```

2. Copy `api/.env.example` to `api/.env` and set `MONGODB_URI` if you want database connectivity. Copy `web/.env.example` to `web/.env` only if you need to change the API URL. Never commit real credentials.

3. Start the frontend and API together:

   ```sh
   npm run dev
   ```

   The web app is available at http://localhost:5173 and the API health endpoint at http://localhost:3001/api/health.

## Commands

| Command | Description |
| --- | --- |
| `npm run dev` | Run the API and web development servers |
| `npm run build` | Build both workspaces for production |
| `npm run typecheck` | Type-check both workspaces |
| `npm run dev --workspace api` | Run the API only |
| `npm run dev --workspace web` | Run the web app only |

The API starts even when MongoDB is unavailable. Its health response reports database connectivity; configure `MONGODB_URI` when a MongoDB instance is available.
